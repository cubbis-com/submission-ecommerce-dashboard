# E-Commerce Public Dataset Dashboard 🛍️

## Deskripsi
Dashboard interaktif untuk analisis data E-Commerce Public Dataset.

### Pertanyaan Bisnis:
1. Kategori produk pendapatan tertinggi & pembatalan terbesar (2017-2018)
2. Distribusi RFM pelanggan (Champions vs At Risk)

## Setup Environment - Anaconda
```bash
conda create --name main-ds python=3.9
conda activate main-ds
pip install -r requirements.txt
